Privacy and credits

This website

This site sets no cookies, uses no analytics and loads nothing from other sites except one request: your browser asks the public GitHub API for the newest WinMux release, so the download links point at it. GitHub receives that request like any other visit to GitHub. The site is hosted on GitHub Pages, which logs visitors' IP addresses in its own server logs; see the GitHub privacy statement.

The WinMux app

WinMux has no account and no telemetry. The only request it makes by itself is the update check against GitHub's release list, plus the download of an update when you install one. Turn off Check for updates on start in Settings and WinMux makes no network requests of its own. Servers you browse in a file pane are the ones you connect to, with credentials you enter. Sessions, settings and profiles stay on your computer, in %APPDATA%\WinMux.
